# wasm-regex-tree

WebAssembly visualizer for Rust regular expressions.

Parses a regex pattern using [regex-syntax](https://docs.rs/regex-syntax) and renders the Abstract Syntax Tree and High-level Intermediate Representation as SVG diagrams in the browser. Pure Rust compiled to WASM, no JavaScript parsing logic.

## Build and run

```bash
make deploy
make serve
```

Then open `http://localhost:8080/app/`.

## Make targets

```
check    cargo fmt --check and cargo clippy
fmt      cargo fmt
clippy   cargo clippy --fix
build    cargo build
test     cargo test
deploy   wasm-pack build, copy WASM and glue JS to app/
serve    python3 http.server on port 8080
```

## Structure

```
src/
    lib.rs       WASM entry point
    ast.rs       node tree from regex-syntax AST visitor
    hir.rs       node tree from regex-syntax HIR visitor
    node.rs      shared Node type
    layout.rs    tree layout algorithm
    svg.rs       SVG rendering
    utils.rs     panic hook
app/
    index.html
    index.js
    wasm_regex_tree.js       generated by make deploy
    wasm_regex_tree_bg.wasm  generated by make deploy
```
